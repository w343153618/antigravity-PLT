# 奖金 收费与商业边界

更新于2026-10-11。用户已确认的商业设想是：客户购买适用方案后若中奖，按奖金总额收取20%服务费，其中店长与平台各取得奖金总额的10%。本文件忠实保留这一设想，并区分尚未确认的合同、税务与经营条件；不构成收费许可或法律意见。

## 用准确的词描述收费

该模式是“中奖后按奖金收费”。它不是“有净利润才收费”，也不是“永远免费”。客户可能中奖却仍亏损；即便不中奖时服务费为0，客户仍然损失购票成本。

应避免未经证实的“投资均衡”“高胜率低风险”“即使亏也不会亏很多”等宣传。控制预算可以约束绝对支出，但不能让独立随机开奖中的某组号码更容易被开出，也不保证净收益。

## 五个不能混用的金额

|名称|含义|
|---|---|
|购票成本 C|本统计范围内实际购买的全部票款，包含未中奖票|
|奖金 G|由彩票中奖获得的奖金，不等于利润|
|已核实税款 T|依法兑奖时实际确认的税款；不由本系统凭单票擅自推断|
|适用奖金 B|事前已适用方案服务且经核实的奖金部分，是服务费基数候选；不包含顾客其他自选中奖|
|服务费 F|按已确认商业设想为 B×20%；其中店长分成候选 B×10%，平台分成候选 B×10%|

当所有票都适用该服务、全部奖金可计费且忽略税款时，B=G，客户净结果=G−C−20%G=80%G−C。否则客户净结果=G−T−C−F，必须把不适用服务的奖金与对应成本一并保留在完整账目中。

|全部适用方案的成本|奖金|服务费20%|店长份额10%|平台份额10%|客户扣费后净结果|

## 为什么不能承诺方案降低长期亏损

在000—999等概率、各期独立、标准固定奖、无额外派奖的模型中：

|一注一倍|覆盖的开奖个数|中奖概率|每2元理论平均奖金|扣奖金20%服务费后的理论平均留存|
|---|---:|---:|---:|---:|
|直选指定号码|1|0.1%|1.0400元|0.8320元|
|组选三指定组合|3|0.3%|1.0380元|0.8304元|
|组选六指定组合|6|0.6%|1.0380元|0.8304元|

上表由官方固定奖金和样本空间推导，不是用户方案实测业绩；服务费按每次中奖全额收取、忽略税款与舍入。理论平均奖金=中奖概率×单注奖金；平均留存再乘80%。平均留存不是净收益，减去2元成本后仍是负数。

来源：[江苏体彩游戏规则](https://api.js-lottery.com/wfzq/p3p5/wfzq/cms/post-49202.html)；[广东体彩2026年第26004期开奖公告对奖金的交叉核验](https://www.gdlottery.cn/f_html/kjgg_pdf_bak/P001_26004.pdf)。

覆盖更多不同号码能提高“至少中一次”的概率，但成本也增加；加倍同一号码则不增加覆盖范围。重叠方案的概率不能直接相加；就算覆盖1000个直选结果，花2000元只得到一注1040元的标准奖。这一极端例子说明中奖率100%仍可亏损；它是教学反例，不是投注建议。

三套方案不会因为分成三份就自动变成风险分散。若同期开奖、号码重叠，结果可能高度相关。任何对外“胜率”都必须说明统计单位、全部期数、全部成本、是否开奖前锁定、是否包含亏损期和服务费。历史回测、短期连中或精选截图都不足以证明未来预测能力。

## 法律与实务核实

《彩票管理条例实施细则》第七条将擅自利用互联网销售的彩票列入非法彩票范围；财综〔2016〕22号同时涉及代销者参与互联网销售或变相销售。平台是否接触资金并不是这些条款中唯一的判断要素。这里能确定需要核实的边界，不能据此判定你具体的方案咨询与收费一定合法或一定违法。[实施细则](https://www.beijing.gov.cn/zhengce/zhengcefagui/201905/t20190522_61500.html)、[五部门通知](https://czj.beijing.gov.cn/zwxx/2024zcwj/2024qtwj/202406/t20240625_3727550.html)

产品建议是先做员工内部登记，不让顾客通过APP提交投注指令、转账或授权自动购票。真实方案发布、客户收费和店长分成作为单独的后续模块，需结合每地经营安排核实后决定范围。这是本方案的审慎产品建议，不是声称某项法律明确禁止所有记录软件。

|找谁核实|带着什么具体问题去|需要留下什么依据|

|试点省体彩机构/门店合同管理方|内部ERP可记录哪些信息？方案合作、中奖收费、店长分成是否与代销合同相容？跨主体多店如何合作？|适用合同、正式规则或针对具体流程的可追溯答复|

## 销售费用 税务与隐私

“体彩给7%”目前只是用户口述。代销者销售费用按其代销合同约定结算，系统要按地区、门店、合同与有效期配置，不能从彩票发行费比例反推门店佣金。[实施细则第五十一条](https://www.beijing.gov.cn/zhengce/zhengcefagui/201905/t20190522_61500.html)

即使某店确实为7%，它乘的是适用销售额；10%的方案分成乘的是适用奖金，二者不能相加成“销售额17%”。例如销售200元、奖金346元：仅按假设计算，销售费用14元、方案份额34.60元，总48.60元，尚未扣营业成本，也不代表店方实际已收。

自2024-09-01施行的口径，电脑彩票一次中奖收入按同一人、同一期、同一游戏全部奖金确定；不超过10000元的暂免个税政策继续执行。超过阈值的实际纳税、兑奖登记与代扣代缴交由有职责的彩票机构按规则处理，不能通过拆票或换店在ERP中制造免税结论。高额奖金在费基未明确前不生成正式应收。[税务总局解读](https://fgk.chinatax.gov.cn/zcfgk/c100015/c5233844/content.html)、[2026年广西税务答复](https://guangxi.chinatax.gov.cn/nsfw/nszx/rdwd/202607/t20260701_435187.html)

客户簿按最小必要原则建立，说明处理目的、范围、保存期限与用户权利；门店和平台须明确各自处理个人信息的角色。店方依法兑奖时需要实名信息，不代表普通客户登记默认要复制身份证到ERP。附件及完整票面按私有权限保护。[个人信息保护法第六、十三、十七、十九条](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/bgt/art/2023/art_f374e8245320413181742e6d1baf4366.html)

## 收费模块启用前要确定的规则

1. 服务适用哪些实际购票明细，顾客何时知情同意，如何保留事前证据？不能中奖后才追认方案。
2. 费基是税前奖金还是实际税后到账？派奖、补奖、跨店兑奖、弃奖、未到账或争议如何处理？
3. 谁向顾客收取服务费？顾客分别付店长/平台，还是店方代收后划分？相应合同、票据、责任如何安排？
4. 店长分成归个人还是经营主体？调岗、离职时按哪一时点归属？
5. 三套方案重叠时，如何将实际购买明细唯一分配或按事前比例分配，保证同一奖金不重复收费？
6. 金额按哪一级汇总舍入？建议仅在约定的结算单级计算到分，分配尾差规则预先固定并展示。
7. 收费纠纷不应在产品设计中变成控制顾客兑奖、扣留原票或强制抵扣的手段；兑奖与服务结算分开核实。

以上未决项需要业务与专业核实。软件可以先保存事实；不要用默认值悄悄替代双方没有明确的约定。
