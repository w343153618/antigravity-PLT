客户档案和累计归属默认展示；其余历史表格默认收起，保留全部数据与记录数。统计口径、核算口径改为按需展开。档案表格去除外层圆角边框，使用单线分隔。角色名称与入口名称分开显示。

策略发布、选号、跟单、余额扣款、登记表单及服务端接口保持原状。本次不包含这些交易流程的界面优化。

## 验证

- 修改前与修改后：`npm run typecheck` 通过，`npm test` 为 17 个文件、213 项测试全部通过。
- `git diff --check` 通过。现有角色隔离断言同步改用新的页面标题，未削减行为断言。
- Codex 内置浏览器：桌面及 390px 手机视口检查；额外在 320px 检查客户和总部档案，没有页面级横向溢出。表格仍在自身容器内滚动。
- 三个账号分别显示“我的 / 门店 / 总部”；客户仅见自己的历史记录及流水。店长显示本店客户档案，无法看到总部累计归属。
- 总部“归属记录”可以点击展开，并用 Enter 收起；键盘焦点留在 summary。折叠入口实测高度 44px，手机日期字段实测 16px。
- 日期筛选到无归属记录的日期时显示空状态，累计归属仍保留两店各 3 位客户；点击“全部日期”恢复 2 条归属统计及 6 条归属记录。
- 浏览器检查未见控制台 warning 或 error。

浏览器使用本机端口 19914、内存 SQLite 和合成演示资料，关闭自动外部数据抓取。没有进行真实交易、线上部署或 Android 安装验证。代码通过独立分支 `codex/minimal-archives` 交付。
